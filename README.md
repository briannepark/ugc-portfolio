# ugc-portfolio

Brianne's UGC / brand-partnership portfolio site. Deploys automatically to
Windmill (as a "Raw App") on every push to `main`.

## What's in here

```
site/                                  ← source of truth: the actual HTML/CSS/JS design
  index.html
  gallery.html
  contact.html                         ← dedicated contact page with a working form
  brands.html                          ← private brand-outreach dashboard (not linked from nav)
scripts/
  build-app.mjs                        ← turns /site/*.html into embedded JS strings
u/brianne/ugc_portfolio.raw_app/       ← the Windmill app (path u/brianne/ugc_portfolio)
  raw_app.yaml                         ← public, custom URL "ugc-portfolio"
  App.tsx                              ← thin wrapper: renders the right page in an <iframe>
  index.tsx                            ← React entry point
  package.json
  pages.generated.ts                   ← generated by build-app.mjs, not committed
  backend/
    submit_contact.ts                  ← sends the contact-form email via SMTP
    brands_list.ts                     ← password-gated: returns the brand list
    brands_save.ts                     ← password-gated: add/update a brand
    brands_delete.ts                   ← password-gated: remove a brand
    brands_send_outreach.ts            ← password-gated: sends an outreach email, logs it
wmill.yaml                             ← limits `wmill sync push` to this app only
.github/workflows/deploy.yml           ← build check + deploy on push to main
```

The site itself stays plain HTML/CSS/JS — nothing was rewritten into React. The
`.raw_app` code is just a small wrapper that loads whichever page's HTML into an
`<iframe>`, so the design stays pixel-exact. A small bridge script (appended to
the bottom of each `site/*.html` file) intercepts clicks on internal links
(`index.html`, `gallery.html`, `contact.html`, and in-page anchors like `#about`)
and asks the wrapper to switch pages, so navigation and "Gallery"/"(More)" links
keep working. The same bridge relays the contact form's submission to the
`submit_contact` backend runnable (and the result back to the form), since the
plain HTML inside the iframe can't call Windmill's backend directly itself.

### Private brand-outreach dashboard

`site/brands.html` is a personal CRM for brand partnerships — not linked from
the public nav, reached directly at `<your app URL>?page=brands`. It tracks a
list of brands with a status pipeline (Not contacted → Contacted → Responded
→ Negotiating → Deal / Passed), notes & tags, rate/offer info, and a running
history timeline per brand, and it can send outreach emails directly (via the
same SMTP setup as the contact form), automatically logging each send to that
brand's history.

It's gated by a password, checked by every backend call (`brands_list`,
`brands_save`, `brands_delete`, `brands_send_outreach`) — not just a
client-side screen — since this app's backend runnables are reachable by
anyone who inspects the public JS bundle. See step 4 below to set the
password.

**Important:** the local folder path (`u/brianne/ugc_portfolio.raw_app/`) has to
mirror the app's actual location in your Windmill workspace (`u/brianne/ugc_portfolio`)
— that's how `wmill sync push` knows which app a given folder deploys to. If you
ever rename the app or move it to a different folder in Windmill, this local path
has to be renamed to match, or the sync will silently deploy nothing.

## To edit the site

Just edit `site/index.html`, `site/gallery.html`, `site/contact.html`, or
`site/brands.html` directly and push to `main` — everything else regenerates
automatically in CI.

## One-time setup

1. **Windmill app.** ✅ Already created at `u/brianne/ugc_portfolio`.

2. **Windmill API token** (Windmill → user settings → tokens) with `apps:write` scope.

3. **Three GitHub repo secrets** (repo → Settings → Secrets and variables → Actions).
   Same values as `brixx-first-birthday`:
   - `WM_BASE_URL` — e.g. `https://app.windmill.dev`
   - `WM_WORKSPACE` — your Windmill workspace id
   - `WM_TOKEN` — the token from step 2 (never share this in chat/PRs — GitHub
     secrets are the right place for it)

4. **Contact form email, in the Windmill UI** (can't be set from this repo):
   - **SMTP resource** at `u/brianne/rsvp_smtp` — reused from `brixx-first-birthday`,
     so if that's already set up, there's nothing more to do here.
   - **Variable** at exactly `u/brianne/contact_notify_email`, value
     `parkbrianne@gmail.com` — this is a separate variable from the RSVP
     notify-email, so contact-form messages don't go to anyone else on the
     RSVP list. Outreach emails sent from the brand dashboard also use this
     as their reply-to address.

5. **Brand dashboard password, in the Windmill UI** (can't be set from this
   repo — never share a password in chat/PRs): create a **Variable** at
   exactly `u/brianne/brand_crm_password` with whatever password you want to
   use to unlock `?page=brands`. The brand list itself is stored automatically
   (as a Windmill **State** resource at `u/brianne/brand_crm_brands`) the
   first time you save a brand — nothing to set up for that part.

6. Push to `main` (or run the "Deploy to Windmill" workflow manually from the
   Actions tab). Open the app in Windmill afterward to confirm a new version
   appears, and to copy its public link (custom path `ugc-portfolio`).
